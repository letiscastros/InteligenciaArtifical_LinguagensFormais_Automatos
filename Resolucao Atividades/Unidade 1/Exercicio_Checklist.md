### O que é um alfabeto Σ; É uma conjuntos de.
Um alfabeto Sigma é um conjunto finito e não vazio.

### O que é uma cadeia; um afkas.

### O que significa ε;
Significa uma palavra vazia, uma cadeia que não possui nenhum símbolo, seu tamanho é = 0, mas não é um espaço em branco, significa apenas que não há nenhum símbolo na cadeia.

### Por que |ε| = 0
Pois o comprimento da cadeia vazia é 0.

### O que é um prefixo;
Parte da palavra que começa no início.

### O que é um sufixo;
Parte da palavra que termina no final.

### O que significa Σ*;
Representa o conjunto de todas as cadeias finitas possíveis de se formar com os símbolos de Σ, incluindo ε.

### Se Σ* possui limite de tamanho;
Não há limite, a quantidade de palavras cresce conforme o tamanho aumenta.

### O que é uma linguagem formal L;
É o conjunto de palavras construídas a partir de um alfabeto, definido por L ⊆ Σ*.

### O que significa L ⊆ Σ*;
L é um subconjunto de Sigma estrela.

### O que é uma gramática formal;
A linguagem formal fornece regras para a geração de palavras.

### O que são terminais e não terminais;
Terminais são os caracteres finais da palavra, enquanto os Não Terminais são conjuntos finitos variáveis.

### O que é uma regra de produção;
S → aS | ε - possui duas possibilidades: S → aS OU S → ε. O símbolo: | significa: OU. Portanto: S pode produzir aS ou ε.

# Base de Dados e Conhecimento (`dados/`)

* `dataset_compartilhamento.csv`: amostra estruturada com os atributos operacionais (`nivel_sensibilidade`, `nivel_permissao`, `qtd_destinatarios`, `pct_externos`) e a classe de risco (`baixo`, `moderado`, `alto`) utilizados no treinamento e teste da Árvore de Decisão.
* `regras_seguranca.csv`: base de conhecimento simbólica contendo as 5 regras de produção (`R1` a `R5`), suas condições lógicas, ações recomendadas e justificativas de segurança da informação.
